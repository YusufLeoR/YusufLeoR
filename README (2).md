## 🚀 Featured Projects

### 🏠 House Price Prediction for Sleman &nbsp;·&nbsp; *Undergraduate Thesis*
End-to-end ML pipeline predicting property prices across **17 districts (kecamatan)** in Sleman, Yogyakarta.
- Cleaned **3,905 raw listings → 1,911 quality records**, with IQR-based outlier removal
- Engineered **12 new features** (physical ratios, university accessibility features)
- Four-method feature selection (SelectKBest, RFE, LassoCV, Random Forest importance) with voting
- Compared **9 models**, tuned with RandomizedSearchCV; evaluated with MAE, RMSE, MAPE, R², Adjusted R²
- Served through a **Streamlit** app

`Python` `XGBoost` `scikit-learn` `pandas` `Streamlit`
